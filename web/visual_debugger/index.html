Actor drafts persist when you cycle or directly control another actor. Scripted scenarios are inspection-only: manual draft and Submit controls are unavailable, and N advances the registered trajectory.

Animation, layout, hover, help, and panel state are presentation-only. Python remains authoritative for every simulator and legality decision. Normal motion briefly holds only the next Submit/Next-frame input; Skip, reduced motion, and Off release it immediately.

This viewer is read-only. Replay transport changes only the selected recorded frame; it cannot submit an action or advance the simulator.
